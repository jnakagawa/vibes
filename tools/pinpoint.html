Install in Chrome

  1. Download and extract the ZIP.
  2. Open chrome://extensions.
  3. Enable Developer mode.
  4. Click Load unpacked and choose the extracted folder.
  5. Pin Pinpoint, open any public page, and start marking it up.

What you get

  • Element-anchored, numbered feedback pins
  • Full-width reviews with native scrolling and selectable text
  • Public collaboration without an account or extension
  • Author-only comment editing through Zero Auth
  • Optional email-domain protection
  • Review revisions hosted on Zero
